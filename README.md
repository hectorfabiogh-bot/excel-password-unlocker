## Features

- Removes worksheet protection (locked cells)
- Removes workbook structure protection
- Unlocks read-only and modify restrictions
- Supports .xlsx, .xlsm, .xls formats
- Batch unlock multiple files at once

## FAQ

**Does it work if the entire workbook is password-protected (can't even open it)?**  
That's a different type of protection (open password). This tool handles sheet/editing protection — not the open password. Use the ZIP method for open-password files.

**Will it break formulas or formatting?**  
No — only the protection flags are removed, all content stays identical.
